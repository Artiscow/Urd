## Mii lea Urd?

Urd lea rabas gáldokoda neahttasiidohuksejeaddji gos **repo maid kloneret LEA du neahttasiidu** - ja neahttasiidu lea iežas huksejeaddji. Nuvttá, statihkalaš, git-oamastuvvon molssaeaktu Squarespace, Wix ja Publii ektui.

Don it dárbbaš servera, diehtovuođu, diŋgojumi iige huksenproseassa. Dušše git-repo lohkkehahtti fiillaiguin maid ieš oamastat. Dál siidu doaibmá Cloudflare Pagesis: dat bálvala siidduid, ja dan Functions-doaimmat gieđahallet sisaloggema ja almmuheami `/admin`-siiddus. Ahte siidu sáhttá bálvaluvvot vaikko guđe statihkalaš hostas (GitHub Pages, Netlify, iežat server), lea plánejuvvon v0.9 várás.

## Ná dat doaibmá

1. **Ráhkat iežat repo** [urd-template](https://github.com/Artiscow/urd-template) mális («Use this template» GitHubas) ja lakte dan Cloudflare Pagesii: [heivehanrávvagat](../setup-publication/SETUP-se.md) čájehit juohke lávkki.
2. **Heivet** siiddu oahpisteaddji bokte - namma, ivnnit, logo.
3. **Doaimmat** go manat čujuhussii `dusiidu.no/admin` ja loggejat sisa GitHubain. Doppe lea olles huksejeaddji: coahkkal ja čále njuolga siidui, gease blohkaid friddja gridii, lasit sekšuvnnaid, doaimmat duogážiid, ivnniid ja navigašuvnna.
4. **Almmut** - okta coahkkaleapmi ráhkada ovtta git-commita du rievdadusaiguin, ja host bálvala ođđa siiddu vuollel minuhtas.
5. **Ođasmahte** - Ođasmahttin-panel adminis viežžá ođđa Urd-veršuvnnaid mállerepos oktan commitin, ja várre fiillaid birra maid don leat gieđain rievdadan.

Maŋŋel vuosttaš heiveheami lea admin-siidu du neahttasiiddu stivrenguovddáš. Buot maid oainnát siiddus sáhttá doaimmahuvvot doppe.

Kaleandar (iCal-feed viđain čájehemiin ja 34 hábmemiin), oktavuohtaskovvi (mailto dahje iežas čuokkis) ja kárta (personsuodjaleaddji OpenStreetMap) leat vuođđoblohkat Blohkat-panelas. Urd sáhttá maiddái viiddiduvvot **pluginaiguin** mat orrot du repos ja mat biddjojuvvojit johtui adminas. Okta čuovvu mielde: ruoŧagiel giellapáhkka, mii lea maiddái ovdamearka sidjiide geat háliidit ráhkadit iežaset. Geahča [template/plugins/README.md](../../../template/plugins/README.md) jus háliidat ráhkadit iežat.

## Njeallje lohpádusa

1. **Don oamastat buot.** Du siidu lea git-repo lohkkehahtti fiillaiguin. Ii makkárge lohkkaseapmi.
2. **Ođasmahttin ii goassege billis huksejuvvon siiddu.** Buot sisdoalus lea `version` + migrerenprográmmat mat dolvot boares dáhtaid oadjebasat ovddos.
3. **Neahttasiidu ii dárbbaš huksenproseassa.** Dat mii lea repos lea juste dat maid fierpmádatlohkki viežžá.
4. **WYSIWYG almmá kompromissaid haga.** Admin čájeha duohta siiddu - seamma mohtor, seamma fiillat.
