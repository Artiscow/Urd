# keep-minutes.js

The full text of the longer comments in the engine's `keep-minutes.js`, in the file's order, under the name each one explains: a declaration by its name, a comment inside a function by the names around it and the code it stands before. The code keeps a short version of each in its place.

## The module

How long the engine keeps what it fetches ahead in a visitor's browser, in minutes.
The modules that keep it read these numbers, and the privacy page names them from here too (privacy-model.js), so its minutes are the code's; a module of its own, so the boot loads no more than it for them.
